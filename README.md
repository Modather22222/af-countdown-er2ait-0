# Countdown

Countdown is a small Material 3 app for tracking the moments you are looking forward to.
Add events with a name, date, time, and emoji, then watch days, hours, minutes, and seconds tick down.
Countdowns live in memory for the current session; delete an event or undo a removal at any time.

Run it with `flutter pub get`, then `flutter run`.
Run the smoke test with `flutter test`.
